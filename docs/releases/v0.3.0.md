# v0.3.0 accepted Source

VMR V1-M007-R013 is the accepted, unreleased 0.3.0 runtime Source baseline.
This document records accepted implementation/validation behavior; it is not a tag,
package publication, Chrome Web Store operation or other publication evidence.

## Accepted additions

- Additive `CaptureMode`: default `BrowserViewport` retains the 0.2.0 CDP behavior;
  `NativeWindow` captures the exact validated owned HWND through Windows Graphics
  Capture `CreateForWindow` without a picker or replacement-window search.
- GPU-first NativeWindow bounding: crop to WGC `ContentSize`, D3D11 video-processor
  resize with no upscale, bounded staging readback, then GDI+ JPEG quality 70.
- Additive `SetShowInTaskbar(Guid,bool)` exact-HWND runtime policy, independent of
  PARK/RESTORE and monitoring, with original state restoration on normal disposal.
- SampleCaller controls for capture mode and selected-session taskbar visibility.

NativeWindow requires Windows 10 version 1903/build 18362 or later and a compatible
D3D11/WGC device. It fails explicitly without falling back to BrowserViewport.
BrowserViewport remains available through the compatible `net10.0-windows` package
asset. The extension still declares debugger permission for BrowserViewport.

Historical GitHub/NuGet 0.1.0 and 0.2.0 releases and the submitted CWS 0.2.0 review
artifact are unchanged. No tag, Release, package push, Store upload or submission is
part of R013 acceptance.
