## Store and user-facing policy

Use the matching 0.2.0 bundle, [future Store copy](../chrome-web-store.md),
[reviewed assets](../store-assets/privacy-review-0.2.0.md) and [privacy policy](../../PRIVACY.md).
PARK/RESTORE controls placement only and never auto-toggles monitoring. Caller owns
the explicit per-session monitoring policy. Paused pixels remain sensitive in-memory
data; silent-debugger suppression is best-effort, and third-display timeout remains unresolved.

Exact local sizes/hashes, logs, screenshot observations and failed attempts belong to
the transient task handoff. Nothing here authorizes stage/commit/push, tag/Release,
workflow dispatch, NuGet publication or a live CWS dashboard action.
